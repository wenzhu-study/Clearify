# Clearify

一个注重质感和隐私的中文图片工具网站，包含高清增强和视频提图。暖白与陶橙色工作台，支持桌面和手机。

## 运行

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地网址，默认是 `http://localhost:5173`。

```sh
npm run build   # 类型检查并生成 dist/
npm run preview # 预览生产构建，包含分享解析 API
npm start       # 用 Node 服务运行 dist/ 和分享解析 API，默认 5173
npm test        # 服务端测试 + 浏览器端到端测试，浏览器使用本机 Chrome
npm run test:server # 单独运行服务端解析和网络访问验证测试
```

完整网站使用 Node.js 部署：运行 `npm run build` 后，保留 `dist/`、`server/`、`package.json` 和依赖，再执行 `npm start`。可通过 `PORT` 指定端口，公网部署时通过反向代理提供 HTTPS。无需数据库或 API 密钥。

抖音动态分享页的读取需要服务器安装浏览器。当前电脑会自动使用已安装的 Chrome；其他部署环境可运行 `npx playwright install --with-deps chromium`。浏览器只在普通解析未得到作品时启动，用全新匿名上下文读取公开作品，结束后立即关闭；不读取个人 Chrome 配置或登录信息。

只部署 `dist/` 的静态网站仍可使用图片增强和本地视频提图，但**分享链接解析需要配套的 Node 服务**。开发和预览命令会自动挂载同一套解析接口。

## 已实现

- 上传、拖拽、粘贴 JPG / PNG / WebP，文件和尺寸校验。
- 2× / 4× 放大，自然 / 细节模式，可选轻柔降噪。
- 在 Web Worker 中运行实际的 Lanczos 3 重采样、边缘锐化和降噪；显示真实阶段进度，支持取消。
- 紧凑侧栏、整屏图片工作台和底部操作区：大图、上传、参数与下载集中在同一视野中，手机端自动调整为纵向布局。
- 增强完成自动回到大图对比，以至少 100% 实际像素显示细节（小图会适当放大）。
- 铺满窗口的全屏预览，支持适应窗口、100% 实际像素、200% / 400% 细节缩放和拖动平移。原图与增强图同步移动和缩放，便于查看同一区域。
- 拖动分隔线比较前后效果，也可切换原图 / 增强图。全屏内用滚轮缩放，页面内用 Ctrl / ⌘ + 滚轮；双击切换放大 / 适应，键盘 `+` / `-` 缩放、`0` 复位、方向键平移，`Esc` 退出全屏。
- 高清 PNG、JPG、WebP 下载；PNG / WebP 保留透明背景，JPG 用白色填充透明区域。
- IndexedDB 本地作品记录，可查看、再次下载和删除。保留最近 12 张，总容量约 120 MB。
- 3 张可操作的示例图片、使用指南、常见问题和移动端导航。
- 字体与示例图片随站点托管，处理用户照片时不请求第三方服务。

## 视频提图

- 新增独立的「视频提图」导航，支持粘贴整段分享文案、剪贴板粘贴、清空和取消。
- 服务端解析公开分享页面中的原图列表或视频地址：兼容抖音 `_ROUTER_DATA` / `RENDER_DATA` / `self.__pace_f.push` 流式数据、小红书 `__INITIAL_STATE__`、TikTok hydration 数据，以及通用 JSON-LD / Open Graph / HTML video 数据。抖音先读取公开图集接口，未得到数据时自动用匿名浏览器打开同一作品并解码动态页面数据，不因一个接口的 403 就认定作品需要登录。平台适配按可公开读取的数据工作，**不保证所有平台、所有分享链接都可解析**；不会把封面、头像或推荐作品冒充成用户分享的图片。
- 公开的 MP4 / WebM 直链可直接读取。暂不支持 HLS / DASH 播放列表、加密视频、直播或需账号登录的媒体；MOV 是否可用取决于浏览器是否支持其编码。
- 视频在浏览器里解码并截图，支持自动去重或等距截图，数量可选 6 / 12 / 24 / 36 张，格式可选 JPG / PNG。自动模式在最多 90 个采样点中寻找不同画面，属于抽样提取，不能保证找出每一个瞬间；达到数量上限时停止。
- 图文内容最多提取 60 张，保留平台提供的原图文件。结果显示图片尺寸、文件大小和视频时间点，支持大图预览、勾选、单张下载和逐张批量下载，还能送到图片增强继续处理。下载名称采用图片序号，如 `1.webp`、`2.webp`、`3.webp`；勾选部分图片时保留对应序号。批量下载直接生成独立图片文件，浏览器首次询问是否允许下载多个文件时选择允许即可。
- 支持本地视频选择和拖入，本地文件不上传；支持 100 MB、30 分钟以内、2400 万像素以内且长边不超过 8000px 的视频。提取结果总量限制为 120 MB，在线单张图片上限为 16 MB。
- 提取结果只保留在当前页面会话中，切换模块不会丢失，刷新会清除。请及时下载；只有送去增强并完成处理的图片会进入「我的作品」。

分享解析会由网站服务访问用户提供的公开链接，媒体使用不可猜测的临时标识访问，服务只作内存缓存（有效期 15 分钟、约 160 MB 上限，在后续请求时清理），不写入磁盘，不使用用户浏览器登录信息。直接 HTTP 请求会校验 URL、DNS 结果和每一次重定向，拒绝内网、回环、特殊地址及非 HTTP(S) 协议，固定解析出的公网连接地址，限制并发、文件大小和读取时间。匿名浏览器仅接受数字抖音作品 ID，导航限定为抖音站内作品页面，其他资源限定为平台域名并检查公网 DNS，禁用 Service Worker、WebSocket 和媒体下载；提取只接受与请求作品编号完全匹配的数据。

验证包含真实本地视频截帧与下载、批量下载的文件数量和序号命名、每张图片的实际内容校验、图文解析数据样例、错误和取消流程。另用 MDN 的公开 `flower.mp4` 链接完成了真实远程解析与 6 张截帧验证。2026-09-30 用用户反馈的抖音 `qcJWKQ6PhcM` 分享完整验证了《于是》3 张谱图的网页提取和下载：尺寸分别为 1290 × 1818、1290 × 1804、1280 × 1816。自动测试覆盖分段流式数据、camelCase 字段、作品编号匹配、接口拒绝后的浏览器回退、取消和错误提示；实际成功率仍受平台当时的公开访问策略影响。

## 处理说明

这是无需模型下载的**本地传统图像增强算法**，不是生成式 AI 超分辨率。它改善放大质量和边缘清晰度，但不能恢复照片中已经丢失的真实细节。首页初始风景对比是明确标注的效果示意；用户上传或选择示例后，处理及对比都使用真实算法结果。

单文件最大 20 MB，输入与输出均限制在 2400 万像素、长边 8000px 以内。超过输出上限时按比例调整，并在增强前显示实际预计尺寸。处理大图会使用更多内存和时间，设备性能会影响速度。

建议使用支持 OffscreenCanvas、createImageBitmap 和 Web Worker 的新版 Chrome、Edge、Firefox 或 Safari。测试配置使用本机 Chrome；其他环境可安装 Playwright Chromium，并移除 `playwright.config.ts` 中的 `channel: 'chrome'`。

## 结构

- `src/App.tsx`：界面、交互与工作流。
- `src/Comparison.tsx`：可缩放、平移的同步图片对比。
- `src/VideoExtractor.tsx`：视频提图页面、结果与下载交互。
- `src/video-extraction.ts`：视频解码、截帧、去重与逐张批量下载。
- `src/video.css`：视频提图模块的响应式样式。
- `server/parse.mjs`：分享文本、图文和视频地址解析。
- `server/douyin-browser.mjs`：抖音公开作品的匿名浏览器读取、域名约束和超时清理。
- `server/remote.mjs`：校验公网地址、限制重定向与媒体下载。
- `server/video-api.mjs`：解析接口和临时媒体访问。
- `server/start.mjs`：生产环境静态资源及 API 服务。
- `src/studio.css`：工作台布局、紧凑导航、底部操作区和全屏预览。
- `src/styles.css`：视觉样式和响应式布局。
- `src/enhance.worker.ts`：独立线程中的图像算法。
- `src/storage.ts`：作品的本地持久化。
- `src/types.ts`：类型、输出尺寸计算与下载。
- `tests/e2e.spec.ts`：实际上传、下载、透明通道、格式、作品记录、取消、错误与移动端测试。
- `tests/video.spec.ts`、`server/tests/`：视频提取、下载和服务端解析测试。
